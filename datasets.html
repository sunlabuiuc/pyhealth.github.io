How to read these snippets. PyHealth does not ship data: download each dataset from its source, then point root at the folder (or URL) holding the raw files. Each card's badge says what that takes (Open: download now; Restricted: free, but sign an agreement or request access; Credentialed: PhysioNet-style credentialing and training first), and Get the data links to the source. The dataset's docs page has the download command and the folder layout. Add cache_dir="..." to keep the processed copy somewhere you control, and dev=True to try 1,000 patients first. To try the API with no download, use the public synthetic copy: MIMIC3Dataset(root="https://storage.googleapis.com/pyhealth/Synthetic_MIMIC-III", tables=["diagnoses_icd"]). Tutorial 01 covers datasets in depth. Snippets checked against PyHealth 2.1.0.
